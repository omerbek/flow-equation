# Flow Equation / Denklem canlandırma

## Türkçe

[Canlı aracı aç](https://omerbek.github.io/flow-equation/).

Hacmin süreye bölünmesiyle debinin nasıl hesaplandığını göster.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda aç. Oynat düğmesini ve zaman çizelgesini kullanarak sekiz saniyelik sahneyi incele. HTML ve Canvas 2D ile çevrimdışı çalışır.


## Sahne ayarları

- Hacim (L)
- Süre (s)

Sekiz saniyelik zaman çizelgesinden bir kare seçip **PNG indir** ile 720 × 405 piksel dışa aktarabilirsin.

## English

Calculate flow rate from volume and elapsed time.

Open [the live tool](https://omerbek.github.io/flow-equation/) or open `index.html` in a browser. Switch between Turkish and English in the page header. Use the timeline to select a frame and **Download PNG** to save it at 720 × 405 pixels.
